# Apple 原生应用：分层界面与交互设计图册

版本 1.0 · 2026-09-20 · 总体窗口 → 区域 → 页面 → 内容组件 → 控件 → 状态。

这是一个完整的纯文本线框图文档。每层都画具体布局、操作入口与状态变化；框线表示结构，不代表生产界面的描边。真实材质、圆角、阴影、系统动效和 Liquid Glass 交给 Apple 原生组件，不从文本图推导 CSS 或自绘玻璃。

本图册统一收纳样式和交互示例，不要求每个例子都成为框架组件。`[名称]` 表示可操作控件；`▾` 表示展开；`✓` 表示选中；示例人名与数据均为虚构。以下均为目标设计，不宣称已实现。

与[总蓝图](ProductPlatformBlueprint.md)配合使用：总蓝图裁决责任与边界，本图册描述用户实际看到和操作的界面。

## 1. 最大层：应用、窗口与区域

### 1.1 通用窗口骨架

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ WINDOW CHROME · 原生窗口 / 标题 / 工具栏                                   │

├────────────────────┬─────────────────────────────────┬─────────────────────┤
│ NAVIGATION         │ WORKSPACE                       │ CONTEXT             │
│ 我在哪里？         │ 主要业务内容                    │ 当前需要的补充信息  │
│ 还能去哪里？       │ Table / Grid / Timeline         │ Inspector / Preview │
│                    │ Editor / Canvas / Form          │ Activity / Utility  │
│ 区域 / 收藏 / 来源 │                                 │                     │
```

操作：切换导航更新工作区；选中内容更新相应上下文；打开/收起辅助区不重建业务状态。Workflow 另行呈现，不能把“导入弹窗”和“调试控制台”视为同一生命周期。

### 2.3 专注模式与恢复布局

```text
┌──────────────────────────┬────────────────────────┐
│ 普通                     │ 专注                   │
├──────────────────────────┼────────────────────────┤
```

[专注] 保存必要的用户布局偏好并收起区域；退出时恢复该用户偏好，不重新创建一棵独立业务视图。

## 3. Window Chrome 与 Toolbar 的具体形态

### 3.1 工具栏的分组

```text
┌────────────────────────────────────────────────────────────────────────┐
│ [侧栏] [后退] 资料库     [播放] [+添加]   [列表 ▾] [搜索____] [上下文] │
│   导航与身份               常用操作          视图与查询       布局     │
└────────────────────────────────────────────────────────────────────────┘
```

常用操作有优先级；完整命令保留菜单入口。系统管理可定制与 overflow 的部分，产品不自造一整套工具栏布局器。

### 3.2 同一路由，不同选择状态

```text
┌──────────────────────┬─────────────────────────┬──────────────────────────────┐
│ 未选择               │ 单选                    │ 多选                         │
├──────────────────────┼─────────────────────────┼──────────────────────────────┤
│ 资料库  [+添加]      │ 资料库  [播放] [更多 ▾] │ 资料库  已选 3 首 [加入队列] │
│ 对象操作不可用       │ 操作目标：Track A       │ 批量菜单显示共同操作         │
│ 搜索和显示控制仍可用 │ 权限/状态决定 enabled   │ 混合状态明确呈现             │
└──────────────────────┴─────────────────────────┴──────────────────────────────┘
```

选择变化直接更新可用条件与原生控件，不通过切换 Route 强制刷新；更新搜索文本或 enabled 不能丢失键盘焦点。

### 3.3 空间不足与 overflow

```text
┌────────────────────────────────────────────────────┐
│ 完整：[添加] [分享] [导出] [视图 ▾] [搜索________] │
│ 缩窄：[添加] [搜索____] [更多 ▾]                   │
│                          ┌──────────┐              │
│                          │ 分享…    │              │
│                          │ 导出…    │              │
│                          │ 显示方式 │              │
│                          └──────────┘              │
└────────────────────────────────────────────────────┘
```

收纳低优先级操作，保留当前任务的主要操作；同一操作的名称、快捷键、可用条件与菜单一致。

选中行表达当前位置，展开三角只改变层级展开状态。项目标题旁的数量若出现，必须有明确含义；不把所有数字都做提醒徽标。

### 4.2 导航与操作的区别

```text
┌─────────────────┬──────────────────────────────┐
│ 导航项目        │ 项目内操作                   │
├─────────────────┼──────────────────────────────┤
│ 资料库 → 工作区 │ [+] → 创建/导入 Workflow     │
```

切换账号/组织先处理未提交输入，使旧请求结果失效，再换数据分区。不能只改侧栏标题继续显示旧组织的数据。


Identity 在合适的原生标题位置呈现，不要求再画一行大标题。范围控制作用于该工作区，内容自身只承担领域内容和交互。

### 5.2 分栏的主从关系

```text
┌────────────────┬────────────────────────┐
│ 集合           │ 详情                   │
├────────────────┼────────────────────────┤
│ 订单搜索与列表 │ SO-0186 完整详情       │
│ ✓ SO-0186      │ 客户 / 条目 / 历史     │
│   SO-0185      │ [编辑] [提交审批]      │
│ 切换选择       │ 无未保存输入则更新详情 │
└────────────────┴────────────────────────┘
```

详情含未保存修改时，切换对象先按草稿策略保存、放弃或取消切换。两栏是同一用例的主从关系，不各自维护互相矛盾的当前对象。

## 6. Search、Filter、Sort 与空结果

### 6.1 搜索输入、建议与结果

```text
┌────────────────────────────────────────┐
│ [搜索] 夜航________________ [×]        │
│ ┌──────────────────────────────┐       │
│ │ 在资料库搜索“夜航”            │      │
│ │ 最近搜索                      │      │
│ │   林川                        │      │
│ │   沿途                        │      │
│ └──────────────────────────────┘       │
│                                        │
│ 结果 2 首                     [排序 ▾] │
│ 夜航                         林川      │
│ 窗外的雨                     林川      │
└────────────────────────────────────────┘
```

输入更新当前查询；清除恢复对应范围。建议与结果分别管理焦点；Enter 的行为由产品明确为提交或接受建议。旧查询的异步结果必须失效。

### 6.2 筛选与排序

```text
┌──────────────────────────────────────────────────────┐
│ [筛选 ▾]                       [排序 ▾]              │
│ ┌──────────────────┐           ┌──────────────────┐  │
│ │ 来源              │           │ ✓ 最近添加       │ │
│ │ ☑ 本地文件        │           │   曲目名称       │ │
│ │ ☐ 外部来源        │           │   作者           │ │
│ │                  │           │ ──────────────── │  │
│ │ [重置] [应用]    │           │ ✓ 降序           │  │
│ └──────────────────┘           └──────────────────┘  │
└──────────────────────────────────────────────────────┘
```

带 [应用] 的筛选先编辑草稿条件；即时筛选则不再放多余提交按钮。排序改变排列，保留仍存在的对象选择。

### 6.3 无结果与请求失败

```text
┌──────────────────────────┬──────────────────────┐
│ 无匹配结果               │ 请求失败             │
├──────────────────────────┼──────────────────────┤
│ 未找到“夜航x”            │ 暂时无法连接内容来源 │
│ 尝试其他关键词或清除筛选 │ 现有结果仍可查看     │
│ [清除筛选]               │ [重试] [检查来源]    │
└──────────────────────────┴──────────────────────┘
```

无结果不显示网络错误；刷新失败不擦掉已有内容。工作区搜索与全局搜索若同时存在，必须清楚标注作用范围。

## 7. Collection：Table、List、Grid、Gallery、Kanban

### 7.1 表格结构与行状态

批量结果逐项展示；[重试失败项] 不重复执行成功项。结果区可以持续存在，直到用户关闭或开始下一项明确替代它的任务。

## 15. Accessory：播放器、状态栏与持续任务

### 15.1 常驻播放器与展开形态

```text
┌────────────────────────────────────────────────────┐
│ 紧凑：夜航 · 林川                    [暂停] [队列] │
│ ──────────────────────────────────────────────     │

└────────────────────────────────────────────────────┘
```

紧凑与展开操作同一 Playback。拖动播放进度先预览目标位置，按能力提交 seek；播放失败在播放器内持续可见并提供重试，不用短暂提示代替。

### 15.2 Queue 与当前播放

```text
┌────────────────────────────────────────────┐

│ ▶ 夜航 · 林川                       [暂停] │
│ ────────────────────────────────────────── │

```

重排只改变未来队列；删除排队项不等于删除曲库记录。当前播放状态与列表选择分开。关键播放命令也要有菜单或完整播放器入口。

### 15.3 状态栏与持续任务展开

```text
┌─────────────────────────────────────────────────┐

└─────────────────────────────────────────────────┘
```

点击状态进入可处理的详情；离线与未提交不能显示为已同步。窗口底部可被遮挡的重要动作需要其他可达入口。

## 16. 更小的输入与呈现组件

### 16.1 标签、值、说明与图标按钮

```text
┌───────────────────────────────────────────────────────┐
│ 资料库名称 *                         ← 字段标签       │
│ [旅行音乐________________________]   ← 输入值         │
│ 用于此设备上显示的名称。             ← 帮助说明       │
│                                                       │
│ 位置      /Music/旅行音乐     [选择…] ← 只读值+操作   │
│ [播放图标]                            ← 有可访问名称  │
│ [图标] 播放                          ← 需要时显示文字 │
└───────────────────────────────────────────────────────┘
```

placeholder 不替代持久标签；必填与错误有文字说明。图标含义应符合原生习惯；不靠 tooltip 提供完成任务必需的信息。

### 16.2 Number、Stepper、Slider 与范围

```text
┌───────────────────────────────────────────────┐
│ 数量       [  2  ] [−] [+]                    │
│ 音量       [静音] ━━━━━●━━━━ [最大]           │
│ 日期范围   [9月20日 ▾] 至 [9月24日 ▾]         │
│ 缩放       [−]       100%      [+] [适合窗口] │
└───────────────────────────────────────────────┘
```

数值有范围、单位和键盘输入策略；达到边界时相应操作禁用。Slider 的连续预览与最终提交按能力分开；高代价写入不因每个像素移动触发一次。

### 16.3 Token 与多选输入

```text
┌────────────────────────────────────────┐
│ 标签 [爵士 ×] [夜晚 ×] [输入标签____]  │
│ ┌───────────────────────────────────┐  │
│ │ 已选：爵士、夜晚                   │ │
│ │ ☐ 原声                            │  │
│ │ ☐ 电子                            │  │
│ │ [创建“旅行”标签]                  │  │
│ └───────────────────────────────────┘  │
└────────────────────────────────────────┘
```

移除 token 只改变该字段；建议选择和新建标签是不同操作。键盘可在 token、输入和建议之间移动，撤销行为按输入组件契约处理。

### 16.4 Breadcrumb、Link 与层级返回

```text
┌──────────────────────────────┐
│ 项目 ▸ 素材 ▸ 海报.pdf       │
│ [返回预订]  R-2026-0186      │
│                              │
│ 客户：青禾设计  [查看客户 ↗] │
└──────────────────────────────┘
```

路径表达当前层级，祖先段可导航；跳转到关联记录按当前/新窗口策略执行。离开有未提交输入的内容先处理草稿，不能静默丢弃。

### 16.5 Badge、状态与进度

```text
┌───────────────┬────────────────────┬─────────────────┐
│ 业务状态      │ 数字计数           │ 进度            │
├───────────────┼────────────────────┼─────────────────┤
│ ✓ 已确认      │ 待审核 12          │ 确定：68 / 112  │
│ ! 需要处理    │ 搜索结果 24        │ ━━━━━━░░░░ 61%  │
│ 草稿 · 未提交 │ 消息计数按实际含义 │ 未知：正在检查… │
└───────────────┴────────────────────┴─────────────────┘
```

颜色只辅助文字与符号。未知总量时不显示假百分比；已确认、提交中、结果未知、被拒绝不能共用一个绿色成功状态。

### 16.6 分页、增量加载与位置

```text
┌───────────────────────────────────────────────┐
│ 显示 1—50 条                        共 128 条 │
│ [上一页：不可用]     第 1 页      [下一页]    │
│                                               │
│ 增量列表末尾：正在加载更多…                   │
│ 加载更多失败：已有内容保留          [重试]    │
└───────────────────────────────────────────────┘
```

分页与增量滚动按产品选择，不强行统一。刷新或删除后尽量保留用户的位置与有效选择；返回列表可恢复稳定定位，不以数组下标长期保存身份。

### 16.7 Drag & Drop 与重排

```text
┌─────────────────────────────────────────┐
│ 普通：  1  远山来信                     │
│         2  缓慢的清晨                   │
│ 拖动：  ───── 插入此处 ─────            │
│         3  岛屿之间                     │
│                                         │
│ 文件拖入：                              │
│ ┌────────────────────────────────────┐  │
│ │ 将 4 个文件加入资料库               │ │
│ │ 支持的操作：复制                   │  │
│ └────────────────────────────────────┘  │
└─────────────────────────────────────────┘
```

拖动预览明确影响范围和操作类型；无效目标显示原因或拒绝。键盘/菜单提供等效操作，不能把拖动作为唯一完成路径。

## 17. 系统反馈与页面状态

### 17.1 Inline error、Banner 与短暂通知

```text
┌──────────────────────────────────────────────┐
│ 字段级：                                     │
│ 名称 [_________________]                     │
│ ! 名称不能为空                               │
│                                              │
│ 页面级：                                     │

│ │ ! 无法刷新；当前显示 10:24 的数据 [重试] │ │

│                                              │

│ ┌──────────────────────────────────────────┐ │
```

错误贴近可修复位置；页面级失败不能只靠自动消失的 toast。只有业务能力真的支持撤销才显示撤销入口。

### 17.2 首次加载、空资料库、无搜索结果

```text
┌──────────────────────┬──────────────────────┬──────────────────┐
│ 首次加载             │ 空资料库             │ 搜索无结果       │
├──────────────────────┼──────────────────────┼──────────────────┤
│ ◌ 正在载入资料库     │ 你的资料库还没有内容 │ 未找到“夜航x”    │
│ 保持导航可操作       │ [添加音乐]           │ [清除筛选]       │
│ 可取消的任务提供取消 │ 解释内容如何进入     │ 保留搜索词供修改 │
└──────────────────────┴──────────────────────┴──────────────────┘
```

只有能代表稳定内容结构时才使用骨架占位；不展示虚假的用户数据。空资料库的主操作与无结果的恢复操作不同。

### 17.3 已有内容上刷新、权限受限与失效对象

```text
┌──────────────────┬──────────────────────┬────────────────┐
│ 刷新中           │ 无权限               │ 对象不可用     │
├──────────────────┼──────────────────────┼────────────────┤
│ 旧内容继续可读   │ 无法查看此记录       │ 该文件已移走   │
│ ◌ 刷新…          │ 联系管理员或换账户   │ [定位文件]     │
│ 失败后保留旧内容 │ 不能显示缓存敏感内容 │ [移除失效引用] │
└──────────────────┴──────────────────────┴────────────────┘
```

权限撤销按产品缓存策略处理；不能把“没有权限”伪装成“没有数据”。对象失效时允许离开或修复，不把场景卡在不可退出的加载态。

### 17.4 提交结果未知与冲突处理

```text

```

检查/重试复用同一操作 ID；不得生成重复交易。冲突处理基于重新加载的版本，不能用最后写入自动覆盖重要业务事实。

## 18. 焦点、键盘与区域协同

```text
┌──────────────────────────────────────────────────┐
│ 焦点在搜索框：                                   │
│ 输入 → 查询；Esc → 关闭建议或退出当前临时状态    │
│                                                  │
│ 焦点在集合：                                     │
│ ↑↓ → 移动选择；Enter → 打开；菜单 → 同一选择目标 │
│                                                  │
│ 焦点在 Sheet：                                   │
│ Tab → 流程内控件；提交/取消 → 返回合理触发位置   │
│                                                  │
│ 焦点切到另一窗口：                               │
│ 菜单 enabled 与命令目标 → 新的 Focused Scene     │
└──────────────────────────────────────────────────┘
```

按平台原生约定处理快捷键，不全局截获所有按键。文本编辑中的删除与列表删除不能混淆。开启辅助区域后焦点变化要有目的，关闭时返回原任务。

```text
┌──────────────────────────┬─────────────────────────┬──────────────────────┐
│ 默认外观                 │ 提高对比度 / 减少透明度 │ 动态字体 / 长文本    │
├──────────────────────────┼─────────────────────────┼──────────────────────┤
│ 原生 Liquid Glass 与层级 │ 系统调整材质与可读性    │ 必要时重排内容       │
│ 清楚的选中与焦点状态     │ 不只靠透明/颜色区分     │ 保留主要操作         │
│ 适度原生动效             │ 遵守 Reduce Motion      │ 不裁掉错误与输入标签 │
└──────────────────────────┴─────────────────────────┴──────────────────────┘
```

本图不自定义玻璃材质参数；具体视觉随平台原生组件。实际产品仍需验证可访问名称、阅读顺序、触控目标、键盘路径和布局。

## 20. 从图册映射到实现

本图册是统一设计入口，不是要求一次实现的组件清单。框架优先承载区域、类型化操作与呈现关系；List/Table/Form/Picker 等直接使用原生 primitive；播放器、时间轴、库存表单、编辑器等保留领域实现。

每个落地切片至少覆盖：默认结构、选中/编辑、忙碌、失败、恢复路径。Preview 使用确定 fixture；行为测试验证任务失效、数据持久化和命令目标；实际平台验收负责原生材质、焦点、无障碍与多窗口。文本图不替代这些验证，也不要求现在运行它们。

图册与总蓝图冲突时：先检查是否把空间位置误当资源寿命，把 UI 状态误当业务提交，把示例画法误当强制组件。真实产品可以调整布局，但必须保留清楚的对象身份、操作范围和失败语义。

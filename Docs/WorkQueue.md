## Product honesty and one-truth pass (owner request, 2026-09)

Goal: every surface shows real data or real capability, each responsibility has one owner and one entry point, and the product reads as manage-your-library first. Boundary: app target and MusicDomain only; no kernel change. Done so far: fake Home cards, Settings rows, Add Music cards, visualizer, both provider settings screens (nothing read them) and the fake MusicBrainz status tab are gone; Sources is the one place for files, folders, servers and Apple Music; Library Cleanup (health scan, batch Get Info / artwork, duplicate review, import review, fingerprints, folder rules) replaces Metadata Center and the whole-library remediation; views get library services from `ApplicationModel.services`. Remaining, in order:

1. **The NAS is not in the library.** Subsonic songs are fetched by `LibraryView` page by page into view state and never enter the index, so they cannot be searched offline, cleaned, de-duplicated or merged with local copies (Sources shows 0 songs for a server). `SubsonicLibrarySyncService.ingest` exists but nothing calls it outside tests, it syncs only the first 100 albums, and it would overwrite the server's source row (type and username). Make server sync a background, resumable, paged job owned by `SourceRuntimeCoordinator`, read NAS songs from the index like local ones, then delete the view-level fetching. Done when a 100k-song server is searchable offline and appears in Library Cleanup.
2. **Get Info bypasses the claims model.** `refreshMetadata` writes catalogue values over scanned values in place: no provenance, no undo, contrary to Music.md (metadata are claims; user override > canonical > tags). Record catalogue results as `metadata_claims` and resolve them; then a Cleanup fix can be reviewed and reverted.
3. **Localization debt.** ~120 hardcoded Chinese UI literals (Browse, Library, Albums, Artists, Playlists, Import Review) bypass the English-source catalog, so ja/zh-Hant/bo users see Simplified Chinese; `ContinuousShelfView` titles are plain `String` and never localize.
4. **Globals inside the library.** Views no longer reach `shared`, but library internals still do (`AppDatabase`, `LocalFingerprintRegistry`, `PathHeuristicRuleStore`, `AcoustIDConfiguration`, `LyricsService`, `SourceRuntimeCoordinator` through `SubsonicClientResolvers`), which is why `LibraryServices.live()` must hand out those same instances. Inject them from the composition root, then delete the statics.
5. **Main-thread work in the import path.** `ImportPipeline`, `AcoustIDFingerprintExtractor` and `AudioTagReader` callers are main-actor isolated by the package default (see AppleClient.md); Chromaprint and Get Info artwork I/O are fixed. Move the remaining file work to actors or detached tasks and measure a 10k-file import.
6. **Dead Home input.** `ListenNowBehaviorSnapshot.heroItem` has no reader since the fake cards went; remove it from the query.
